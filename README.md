# Banking Management System (Java)

A console-based banking application built with core Java and OOP concepts.

## Features
- Create account
- Deposit and withdraw money
- Check balance
- Transfer between accounts
- View all accounts
- Custom exception handling (`InsufficientFundsException`)

## Tech Stack
- Java 17+
- OOP (classes, encapsulation, exceptions)
- Collections (`ArrayList`)

## How to Run
```bash
javac BankingSystem.java
java BankingSystem
```
